## 🚀 Deployment (Netlify)

This project is ready for direct deployment via GitHub + Netlify:

1. Push this repo to GitHub  
2. Go to Netlify → “Import from GitHub”  
3. Set:
   - **Build command:** *(leave empty)*
   - **Publish directory:** `/`

Done. Your site goes live instantly.

## 🎞️ Animation System

The headline animation uses GSAP:

- Randomized rotation and skew effects
- Blur-in cinematic reveal
- Looping yoyo animation
- Smooth easing for organic motion

This creates a floating, unstable-but-controlled typography feel.
